
# 🌐 Networking-Projects

This repository contains networking projects that I have built while learning **Computer Networking** to strengthen my theoretical concepts through practical implementation.

## 📁 Projects

This repository currently contains the following four projects:

### 1. Inter-Department Network Design
A network design project focused on establishing connectivity and communication between different departments.

**Folder:** `inter-department-network-design/`

### 2. Small Home Office Network Design
A network design project focused on designing and implementing a network infrastructure for a small home office environment.

**Folder:** `small-home-office-network-design/`

### 3. Hotel Management Network Design
A network design project focused on designing a network infrastructure for a hotel, providing connectivity across different departments.

**Folder:** `hotel-management-network-design/`

### 4. Campus Network Design
A network design project focused on designing and implementing a campus-wide network infrastructure to provide connectivity across different buildings and departments.

**Folder:** `campus-network-design/`

## 📂 Project Structure

Each project follows a similar folder structure:

```text
Project-Name/
│
├── Packet-Tracer/
│   └── project-file.pkt
│
├── Screenshots/
│   ├── scenario.png
│   └── final-topology.png
│
├── Configuration/
│   └── configuration-files
│
└── README.md
```

### Folder Description

- **Packet-Tracer/** – Contains the Cisco Packet Tracer `.pkt` file.
- **Screenshots/** – Contains screenshots of the project scenario and final network topology.
- **Configuration/** – Contains network device configuration files.
- **README.md** – Contains detailed information about the individual project, including its objectives, design, implementation, and configurations.
